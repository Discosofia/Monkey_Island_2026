# Monkey Island 2026 🐒🏝️

> Nombre de trabajo. Ver las alternativas en el [GDD §15](docs/GDD.md#15-nombre-alternativas).

Juego de supervivencia **PvE + PvP opt-in** para **Roblox** (móvil + PC), para hasta **20 jugadores** por servidor.

Naufragas en una isla tropical sin salida, infestada de monos carnívoros de distintas especies y categorías. Desde el **Basecamp** del centro de la isla los jugadores salen a explorar y recolectar, craftean y construyen, resisten las noches, rescatan huevos que se convierten en mascotas y derrotan a los jefes de cada bioma para encender la **baliza de rescate**.
