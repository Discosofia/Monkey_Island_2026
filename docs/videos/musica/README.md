# Música de los Shorts

Pistas propias o con licencia para los Shorts, por energía. Se elige la carpeta según el Short y se pone en CapCut a -10 dB.

| Carpeta | Para qué |
|---|---|
| `alta/` | Jefes, PvP, erupciones: ritmo rápido, percusión |
| `media/` | Roles, mascotas, monturas: aventura, ligera |
| `baja/` | Cierres, paisajes, nido: suave |

Nombre del archivo: `<energía>-<tono>-<duración>.mp3` (por ejemplo `alta-tribal-30s.mp3`).

## Registro de licencias

Cada pista nueva se apunta aquí con su origen y si se puede usar en vídeos monetizados. Sin fila no se usa.
